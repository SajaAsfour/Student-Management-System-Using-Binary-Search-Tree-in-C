# 🎓 Student Management System Using Binary Search Tree in C

## 📌 Overview
This repository contains my **C implementation** of a **Student Management System** using a **Binary Search Tree (BST)**. The program allows for efficient insertion, deletion, searching, and listing of student records based on their **Student ID or Name**.

## 🛠 Features
- ✅ **Insert new student records** with ID, Name, City, Class ID, and Enrollment Date.
- ✅ **Search for a student** by ID or Name.
- ✅ **Update student information**.
- ✅ **List all students** in lexicographic order of their names.
- ✅ **Search for students** by city or class ID.
- ✅ **Delete student records** by ID or Name.
- ✅ **Save student records to a file**.

## 📂 Contents
- 📜 **C Source Code:** Implementation of the BST-based student management system.

## 📌 Requirements
- C Compiler (GCC, Clang, or MSVC)
- Basic knowledge of binary search trees (BST)
